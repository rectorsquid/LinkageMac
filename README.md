# LinkageMac
Downloads and info for the Linkage Mechanism Designer and Simulator app for Mac

## Beta Testing

Try the latest test version of Linkage for Mac through TestFlight:
[Join the Linkage beta](https://testflight.apple.com/join/CvSB1DDf)

Requires the TestFlight app, available free from the Mac App Store.

The latest app is also in a zip file that can be found in the Releases area. Look for the app there if you dont want to use TestFlight to get the open beta app.
